TikTok (through the TikTok website)

      
TikTok doesn't let personal tools post through its API, so Chipper uses the TikTok website in a real browser that you log into. Press Log in to TikTok: a browser window opens on this PC. Log in there (scan the QR code with the TikTok app is easiest). After that, TikTok shows up when you post.

        TikTok doesn't allow automated uploads and may warn, limit or ban accounts it catches. Chipper keeps it gentle (only when you press Post, max 10 a day, 10 min apart) and stops if TikTok asks for a security check. Use it on accounts you can afford to risk.
